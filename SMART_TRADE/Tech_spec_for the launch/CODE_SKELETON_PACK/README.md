# CODE_SKELETON_PACK

## Назначение

Это каркас проекта для Codex и разработчиков.

Он не является отдельной спецификацией. Он существует, чтобы:
- не придумывать структуру каталогов с нуля;
- иметь фиксированные имена модулей;
- иметь точки входа и TODO-контракты для реализации;
- ускорить работу Codex по PART-подходу.

## Главные правила

1. Ничего не удалять.
2. Реализацию вести поверх этого каркаса.
3. Имена файлов и модулей не менять без крайней причины.
4. Истина о логике — в master spec, а не в skeleton.

## Основные служебные файлы

- `PART_STATUS.md`
- `CHANGELOG.md`
- `TODO.md`
- `PROJECT_TREE.txt`
- `pyproject.toml`
- `.env.example`
